# 📄 AI-Resume Builder and Analyzer (ARBA) — AI‑помощник для анализа резюме

> Интеллектуальный инструмент для загрузки резюме, конвертации в изображение и получения детального AI‑отзыва с оценками ATS и персональными советами по улучшению.

**Онлайн-версии:**
- **Puter:** [https://puter.com/app/jsm-ai-resume-analyzing-level-up](https://puter.com/app/jsm-ai-resume-analyzing-level-up)
- **Vercel:** [https://ai-resume-builder-analyzer-n029rwk31-komilovsg-projects.vercel.app/](https://ai-resume-builder-analyzer-n029rwk31-komilovsg-projects.vercel.app/)

## ✨ Возможности

- 📤 **Загрузка PDF‑резюме** — простой drag & drop интерфейс
- 🖼️ **Конвертация в изображение** — автоматическая обработка PDF файлов
- 🤖 **AI‑анализ резюме** — детальный отзыв с оценками и рекомендациями
- 📊 **ATS‑оценка** — проверка соответствия системам отслеживания кандидатов
- 🌍 **Мультиязычность** — поддержка английского, русского и таджикского языков
- 💾 **Облачное хранилище** — все данные сохраняются в Puter
- 📝 **Мастер создания резюме** — пошаговый визард для создания резюме
- 🎨 **Предпросмотр резюме** — несколько стилей оформления (Classic, Minimal, Modern)

## 🔌 Интеграция с Puter (BaaS)

Проект использует [Puter](https://puter.com) как **Backend as a Service (BaaS)** платформу. Это означает, что **нет отдельного бэкенд‑сервера** — все сервисы предоставляются через клиентский SDK `Puter.js`, который загружается в браузер.

### Архитектура

Приложение работает по **serverless** модели:
- Все операции выполняются через `window.puter` API в браузере
- Данные хранятся в облаке Puter
- Аутентификация и авторизация управляются Puter
- AI‑запросы обрабатываются через Puter AI Gateway

### Сервисы Puter

#### Файловое хранилище (FS)
- Загрузка и сохранение PDF‑файлов резюме
- Хранение конвертированных изображений
- Управление файлами пользователя

#### Key-Value хранилище (KV)
- Сохранение результатов анализа резюме
- Кэширование данных пользователя
- Хранение метаданных резюме

#### AI‑аналитика
- Интеграция с Claude AI для анализа резюме
- Генерация персональных рекомендаций
- ATS‑оценка резюме

#### Аутентификация
- Вход через Puter Auth
- Управление сессиями пользователя

### Реализация

Все взаимодействие с Puter инкапсулировано в Zustand store (`app/lib/puter.ts`), который предоставляет единый интерфейс для работы с:
- `puter.auth` — аутентификация
- `puter.fs` — файловое хранилище
- `puter.kv` — key-value хранилище
- `puter.ai` — AI сервисы

**Конфигурация:** Все настройки и логика работы с Puter находятся в `app/lib/puter.ts`

## 🔄 Сценарий работы

### Анализ существующего резюме

1. **Аутентификация** — пользователь входит через Puter Auth
2. **Загрузка PDF** — пользователь загружает PDF‑файл резюме через drag & drop
3. **Конвертация** — приложение конвертирует PDF в изображение с помощью `pdfjs-dist`
4. **AI‑анализ** — отправка запроса к Claude AI с локализованной инструкцией
5. **Сохранение** — результат сохраняется в KV‑хранилище Puter
6. **Отображение** — показ карточки резюме с оценками ATS и рекомендациями

### Создание нового резюме

1. **Запуск визарда** — пользователь переходит на страницу создания резюме
2. **Заполнение данных** — пошаговое заполнение информации:
   - Заголовок и профессия
   - О себе (About)
   - Опыт работы (Experience)
   - Навыки (Skills)
   - Языки (Languages)
   - Рекомендации (Recommendations)
3. **AI‑генерация** — автоматическая генерация текстов через AI
4. **Предпросмотр** — выбор стиля оформления и предпросмотр
5. **Сохранение** — сохранение готового резюме

## 🐛 Решение проблем

### Ошибка AI 400 (Permission denied / usage-limited-chat)

**Проблема:** Ограничение со стороны AI‑делегата Puter.

**Решение:**
- Проверьте лимиты использования AI в вашем аккаунте Puter
- Убедитесь, что у вас есть доступ к AI‑функциям
- Приложение отображает понятное сообщение об ошибке и останавливает загрузку

### Большой GIF на странице загрузки

**Проблема:** GIF занимает слишком много места.

**Решение:** GIF отцентрирован и ограничен по ширине через Tailwind‑классы. При необходимости измените `max-w-*` класс в компоненте.

### Проблемы с локализацией

**Проблема:** Переводы не отображаются корректно.

**Решение:**
- Проверьте, что файлы переводов (`en.json`, `ru.json`) существуют в `locales/`
- Убедитесь, что `i18n.ts` правильно инициализирован
- Проверьте ключи переводов в компонентах
